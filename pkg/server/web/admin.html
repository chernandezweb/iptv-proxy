📡 Smart Shared Stream Relay (Multiplexing) Direct 1:1

When enabled, if multiple devices/accounts watch the same live TV channel simultaneously, the proxy fetches 1 single upstream connection and multiplexes it locally to save your IPTV provider connections. When disabled, each device streams directly with 1:1 pass-through.

🎭 Pass Original Client User-Agent Masquerade (IPTVSmartersPro)

Forward the client player's genuine User-Agent (TiviMate, VLC, Televizo) directly to your IPTV provider instead of masking it with IPTVSmartersPro. Useful if your provider limits multiple streams sharing the same User-Agent.
